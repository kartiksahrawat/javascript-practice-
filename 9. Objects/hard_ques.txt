  city: "Delhi"
};

  age: 21,
  city: "Gurugram",
  course: "BTech"
};

- Original objects must remain unchanged.

Q5. Ultimate Nested Object Challenge~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Given:
let users = [
  {
    name: "Aman",
    address: { city: "Delhi" },
    skills: ["HTML", "CSS"]
  },
  {
    name: "Kartik",
    address: { city: "Gurugram" },
    skills: ["JavaScript", "React"]
  },
  {
    name: "Rohit",
    address: { city: "Delhi" },
    skills: ["Python", "JavaScript"]
  }
];

Perform these operations:
1. Print all user names.
2. Find users living in Delhi.
3. Find users having JavaScript in their skills.
4. Create a new array containing only names and cities.
5. Create a shallow copy of the users array.
6. Safely access a potentially missing property using optional chaining.
